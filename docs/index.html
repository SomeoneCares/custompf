📦 Custom pfSense Packages Repository

A FreeBSD pkg-compatible repository hosting custom pfSense packages. Add this as a custom repository in pfSense and install packages directly from the Package Manager.

🔗 Repository URL

https://SomeoneCares.github.io/custompf/

📦 Available Packages

pfSense-pkg-flexiwan

v1.0.0  net

Integrates pfSense with the FlexiWAN SD-WAN central management platform (flexiManage). Provides device registration, configuration synchronization, health monitoring, and a native pfSense web UI — without replacing any existing pfSense functionality.

Install: pkg install pfSense-pkg-flexiwan

⬇ Download pfSense-pkg-flexiwan-1.0.0.pkg

🔧 How to Add This Repository to pfSense

Method 1: SSH (Recommended)

SSH into your pfSense device and run:

# Step 1: Download the repository public key
fetch -o /usr/local/etc/pkg/custompf.pub \
  https://raw.githubusercontent.com/SomeoneCares/custompf/master/keys/custompf.pub

# Step 2: Create the repository configuration
cat > /usr/local/etc/pkg/repos/custompf.conf << 'EOF'
custompf: {
  url: "https://SomeoneCares.github.io/custompf/",
  signature_type: "PUBKEY",
  pubkey: "/usr/local/etc/pkg/custompf.pub",
  enabled: yes,
  priority: 10
}
EOF

# Step 3: Update package catalog
pkg update

# Step 4: Install the FlexiWAN package
pkg install pfSense-pkg-flexiwan

Method 2: pfSense Shell (GUI)

1. Log in to pfSense WebGUI
2. Navigate to Diagnostics > Command Prompt
3. Paste and run the commands from Method 1 above
4. Navigate to System > Package Manager > Available Packages and search for flexiwan

🔒 Security

All packages are signed with an RSA-4096 key. The public key is available at keys/custompf.pub. When you configure pfSense to use signature_type: "PUBKEY", pkg will verify every package before installation.
